# 首次使用与个人资料访谈

用户表示初次使用、从零建立 Atlas、希望被引导完善资料时加载。未配置仓库且用户希望开始使用时，先介绍再收集连接信息。已有有效 Atlas 的用户直接按既有内容续办，不重复初始化或重新盘问；仅编辑 Skill 不运行此业务流程。

## 1. 先介绍功能与使用方式

用简短、面向用户的介绍说明：

- Personal Atlas 把用户愿意保存的经历、项目、偏好、目标与关系整理为可修改的个人资料库，保留原话、来源与时间，支持检索、纠错、更新和删除。
- 资料存在用户选择的 Git 仓库，Markdown 保存细节，JSON 图组织人、机构、地点、事件、项目及其关系。使用 agent 已有工具访问，不需要专用远端脚本。
- **可以生成可交互、可离线浏览的 HTML Atlas 图谱**，支持搜索、筛选、关联探索与时间线。建议先完善几个主题、积累具体经历和关系，再生成第一版，方便查看缺口和纠错；不要求全部问题答完。图内是完整关系图与摘要，完整正文及原件通过仓库链接查看。
- 用户可按编号回答，也可自由叙述、提供已有材料；任何问题均可跳过、标记未知或指定“只在本轮讨论，不保存”。不索取密码、令牌、身份证号、账户号等秘密。敏感主题只保存用户愿意保留的范围。
- 建库访谈的回答会作为来源整理并提交到所选仓库；先说明该保存方式，确定用户希望保存的范围。若用户只想试用或讨论，不发布其资料。普通 Git 删除保留历史，HTML 也包含个人摘要，不冒称匿名或已彻底遗忘。

随后请用户提供一个用于 Atlas 的空 Git 仓库地址，并说明建议使用私有专用仓库，创建时不添加 README、许可证或其他初始文件；支持 GitHub、GitLab、Gitee 和自建服务。若上下文已有仓库配置，直接采用并检查，必要时确认这是其希望初始化的目标，不重复索取。同轮可询问已连接何种读写工具、需要保存哪些主题；先不要发送整套个人问卷。

## 2. 连接、权限与初始化

按 storage.md 和 connector.md 解析配置并发现工具。本机配置不可访问时使用上下文或上层 plugin 说明继续。

1. 核对目标仓库及当前授权身份，读取仓库元数据、默认/指定分支和文件清单，确认空库。没有提交/分支是空仓库的合法状态，不能以缺少 vault.json 或 HEAD 单独判断空库；404、权限拒绝、截断和无法列目录均不证明仓库为空。
2. 确认现有能力支持读取与写入目标仓库、空库初始化、一次提交多个文件和并发保护。优先已连接的 MCP/插件或已授权 Git/CLI；权限元数据可作初步判断，读取成功不能证明有写权限。
3. 缺能力或授权时，指出具体缺口，指导连接适配的 MCP/插件并授权目标仓库读写。只有所选现有能力需要 PAT 且没有可用授权时，指导用户在该工具支持的外部配置/凭据界面提供具有目标仓库读写权限的 PAT；不要求在聊天中贴令牌，也不自己实现认证。已有连接足够时无需另给 PAT。
4. 用户已接受上述建库流程并提供目标后，在其授权范围内按 mutations.md 的 init 生成目录，由现有工具提交。非空且非 Atlas 的目标停止初始化，提示换空仓库，不覆盖或清空。已有 Atlas 校验并复用，继续访谈。只读工具、分支保护或不支持空库写入时报告真实阻塞，不反复盲目重试。
5. 写入后从远端读取实际提交、vault.json、graph/root.json 及初始化文件，确认内容与校验一致，才报告初始化成功及该仓库实际可读写。只在内存生成 prepared 不能算成功。保留 vault ID，配置仍在 Skill 外。

**远端初始化确认完成后**开始资料问卷。阻塞期间可解释问卷主题；不诱导用户先提交大量无法保存的个人资料。用户明确愿意先聊时可继续，但说明尚未远端保存，不建立本地待同步资料库。

## 3. 访谈组织与续办

默认采用“按主题批量提问 → 用户自由回答 → 来源保存与记录整理 → 下一主题”的方式。每轮给出一个主题的完整问题组（通常 6–10 个），用稳定编号便于作答；不用短文本选择题工具承载长问卷。用户想一次收到全部主题时，可直接给出完整编号题单并允许分批答。先提供 12 个主题的简短目录，随后发送第一个主题的问题。

第一遍优先覆盖全部主题，再作深入追问；用户可调整顺序、跳过整组或随时停下。根据已知内容省略已回答的问题，按职业、人生阶段及材料调整措辞，不假定用户在校、就业、已婚或有特定资产。用户回答简略也可进入下一主题；只有歧义会影响保存准确性时先澄清。用户主动深入某主题时遵循其选择。

问题优先引出：具体对象与名称/别名、现实日期或阶段、事件与决策原因、结果、当前/过去状态、关联人物或项目、例外和来源。引导关系应问“谁/什么影响了它、它属于哪个项目、与哪个阶段相关”，不要把共现当关系或替用户推断心理结论。

每轮处理：

1. 从最新远端快照读已有资料与访谈进度，仅导入用户授权保存的回答；“不保存”内容不得进入原始 source、摘要或图。不以问卷预设推断用户事实，未回答不等于否认。
2. 按 ingestion.md 保留准确原话与问题编号定位，按 schema.md 提取小主题记录、实体、事件/状态、时间和有依据的关系；同一事实合并证据，不写一份包揽全人的长正文。
3. 原始来源可先安全发布，再将提取记录、来源覆盖状态与图同提交发布。分别报告“原文已存”和“整理已完成”，失败时按真实状态续办，不声称全部成功。
4. 简短反馈已整理的要点、仍不确定或未回答的范围，再给下一主题问题。无需让用户逐条确认已明确授权且含义清楚的事实；推断、冲突或含义模糊时保留不确定性/必要澄清。
5. 在远端普通导航记录（basis=navigation）中维护题单版本、主题状态、已回答编号、跳过/待补主题、下一步及来源 ID。不得用新的虚构事实补齐进度；“第一遍已问完”不等于“全人生资料完整”。跨轮续办从此记录与来源读取，不依赖本地缓存。

至少数个主题已有足够实体、经历、关系和时间信息，或第一遍访谈结束时，主动建议生成 HTML 图谱，让用户查看已整理范围、未处理来源和缺口。没有固定数量门槛；用户想早点看也可直接生成，不强迫完成问卷。建议可说：“这些信息已经能形成一版 Atlas 图谱，要不要生成可搜索、可筛选的 HTML，看看关系和还缺哪些内容？”接受后按 visualization.md 生成；不因继续答题自动生成/发布网站。

## 4. 主题题库（第一遍）

题库是覆盖框架，选择与用户相关的问题；保留主题编号便于记录进度。每个问题可用条目、故事或材料回答；年代不清楚可给大致阶段。

### A. 基本背景与使用目标

A1. 希望如何称呼你？有哪些常用名字或别名需要关联？
A2. 愿意记录哪些背景：年龄段、成长地区、常用语言、目前生活城市或时区？可只给大致范围。
A3. 目前有哪些主要身份或角色？哪些属于过去，分别是什么阶段？
A4. 最希望 Atlas 帮你解决什么：回忆经历、管理项目、支持决策、整理关系、规划未来，还是其他？
A5. 有哪些优先整理、暂不整理或不愿保存的主题？别人能否查看你的仓库/导出 HTML？
A6. 已有哪些材料可供后续导入：简历、日记、项目笔记、聊天片段等？只描述你愿意提供的内容。
A7. 对 AI 如何称呼、回答、追问、保存和纠错，有哪些偏好或边界？
A8. 如果只用几个关键词概括现在的生活，你会选择什么？哪些是自我描述，哪些只是暂时感受？

### B. 成长经历与人生阶段

B1. 从成长至今，想保留哪些阶段及大致起止时间、地点？
B2. 哪些搬迁、环境变化或家庭变化影响较大？发生在什么阶段？
B3. 有哪些转折事件？经过、参与者、原因和结果是什么？
B4. 哪些人、地方或经历深刻影响了你？具体影响体现在哪里？
B5. 有哪些值得记住的成就、困难、失败或重新开始？你如何理解它们？
B6. 哪些习惯、兴趣或观念随着阶段改变了？有没有反例或例外？
B7. 哪些经历常被别人误解，或你希望保留完整来龙去脉？
B8. 这些经历有哪些现成资料可佐证或补充？哪些日期和细节暂时不确定？

### C. 教育与学习

C1. 有哪些学校、专业、课程或学习阶段？大致时间和状态是什么？
C2. 为什么做这些学习选择？哪些目标后来改变了？
C3. 哪些课程、老师、同伴或学习项目影响最大？具体发生了什么？
C4. 擅长哪些知识与技能？有哪些成果或使用经历，而不只是自评？
C5. 学习方法、资料来源和复习习惯是什么？什么方式效果差？
C6. 当前在学什么、卡在哪里，有哪些考试、证书或期限？
C7. 对语言、技术或其他长期学习有哪些规划和资源限制？
C8. 有哪些重要作品、研究、比赛或学习决定值得单独保存并关联？

### D. 工作、职业与协作

D1. 有哪些工作、实习、志愿或其他职业经历？机构、角色和时间是什么？
D2. 各阶段主要职责、具体成果和挑战是什么？哪些仍在继续？
D3. 为什么加入、转岗、离开或改变方向？决策背景与结果是什么？
D4. 哪些同事、导师、客户或合作方值得记录？你们合作过什么？可用代称。
D5. 你擅长什么协作角色？沟通、反馈、分工和冲突处理有什么偏好？
D6. 喜欢或避开什么工作环境、任务、节奏与管理方式？有哪些例外？
D7. 当前职业目标、机会、风险和待决定事项是什么？
D8. 有哪些可以关联的项目、作品、重要反馈或阶段总结？

### E. 项目、作品与创造

E1. 正在做和曾做过哪些项目/作品？名称、别名、主题和起止阶段是什么？
E2. 每个重要项目解决什么问题，服务谁，为什么开始？
E3. 你承担什么角色？合作人、机构及相关项目是什么？
E4. 有哪些里程碑、成果、发布或中止？当前状态和证据是什么？
E5. 关键方案和决策如何形成？考虑过什么替代方案，受到什么约束？
E6. 使用哪些工具、资料或方法？与其他项目有哪些依赖、继承或冲突？
E7. 当前最难的问题、下一步和截止日期是什么？
E8. 有哪些教训、值得复用的经验和你愿意保存的文档/链接？不要提供私钥或凭据。

### F. 人际关系与重要人物

F1. 哪些家人、朋友、伴侣、导师或伙伴是重要人物？可只给昵称或代称。
F2. 何时、何地、因何认识？关系经历过哪些阶段？
F3. 有哪些共同经历、项目、地点或重要事件需要关联？
F4. 对方曾怎样影响或支持你？哪些是明确事实，哪些是你的感受？
F5. 希望如何维护这些关系？有何沟通偏好、边界或需要记住的约定？
F6. 哪些关系正在变化、需要投入或暂时不想讨论？
F7. 有哪些社群、组织或圈子，你的角色及参与时间是什么？
F8. 对第三方资料的保存有何限制？哪些内容只保存你自己的经历，不记录对方隐私？

### G. 日常生活、环境与习惯

G1. 典型工作日和休息日怎样安排？有哪些固定或季节性节奏？
G2. 当前居住/活动环境有哪些影响生活的特点？不需要详细住址。
G3. 作息、饮食、运动、通勤和休息有哪些习惯、目标或例外？
G4. 如何安排注意力、任务、时间和精力？哪些方式对你有效或无效？
G5. 家务、出行、购物或生活组织有哪些偏好和常见困扰？
G6. 使用哪些个人设备、应用或工作环境？它们分别服务什么用途？不记录认证信息。
G7. 哪些习惯想保持、改变或建立？背景、障碍和尝试过的方法是什么？
G8. 近期环境或节奏有何变化？与哪些项目、人物或人生阶段相关？

### H. 兴趣、审美与偏好

H1. 长期兴趣和最近的新兴趣是什么？从何时、因何开始？
H2. 喜欢哪些书、音乐、电影、游戏、运动、旅行或其他活动？有什么代表例子？
H3. 哪些作品、创作者、地点或活动影响了你？具体原因是什么？
H4. 在食物、饮品、空间、衣着或设计上有哪些偏好与忌好？
H5. 喜欢怎样的体验和风格？哪些偏好取决于场合、预算或伙伴？
H6. 兴趣有什么实践、作品或社群参与？和哪些人一起进行？
H7. 有哪些愿望清单、计划尝试或曾经放弃的兴趣？
H8. 哪些旧偏好已改变？有哪些容易被误判、需要注明的例外？

### I. 价值观、自我理解与重要决定

I1. 目前最重视哪些价值、原则或生活追求？有何具体例子？
I2. 决策时如何取舍安全、自由、成就、关系、金钱或时间等因素？
I3. 哪些重要决定值得保留过程：背景、选项、约束、选择和结果？
I4. 哪些原则曾改变？发生了什么，不同阶段分别怎样理解？
I5. 你认同的优势、局限和需要成长的方面是什么？有哪些事实支持或反例？
I6. 面对不确定、压力或冲突时，通常如何应对？哪些帮助有效？
I7. 有哪些别人对你的判断，你认同、不同意或尚不确定？
I8. 哪些故事最能说明你希望成为什么样的人？不要根据答案自动做人格诊断。

### J. 健康、精力与支持（可选）

J1. 是否希望记录这个主题？希望保留哪些范围，哪些不保存？
J2. 当前身体、情绪或精力有哪些会影响计划的情况？可仅描述功能影响。
J3. 作息、运动、饮食或休息中，什么有助于状态稳定？
J4. 有哪些自己已明确的需求、限制或专业建议需要被记住？可不给诊断名称。
J5. 状态在什么时期发生过变化？关联哪些环境或事件？不要把相关当因果。
J6. 面临压力时有哪些可用支持：人物、习惯或资源？
J7. 有哪些想改善的目标、可行步骤和需要避开的做法？
J8. 哪些内容只用于安排生活，不能据此推断诊断或替代专业意见？

### K. 资源、财务与现实约束（可选）

K1. 是否希望记录这个主题？可只给范围、原则和约束，不给详细数额。
K2. 时间、资金、设备、空间或协作资源有哪些现实边界？
K3. 收入、支出、储蓄或预算安排有哪些与你的目标有关的原则或变化？
K4. 有哪些重要资产、购买、承诺或长期责任需要关联？无需账户号或产权证号。
K5. 对消费、风险和投入有什么偏好？在哪些场合有例外？
K6. 有哪些重大资源决策？背景、备选、结果和相关项目是什么？
K7. 当前有哪些限制、机会或不确定性影响计划？
K8. 哪些细节不希望保存或在 HTML 中展示？不提供密码、PAT、银行卡等秘密。

### L. 目标、未来计划与访谈回顾

L1. 近期、中期和长期目标分别是什么？为何重要？
L2. 每个重点目标的具体结果、期限和完成标准是什么？尚未确定可保留未知。
L3. 目标之间有什么依赖或冲突？先后顺序和取舍是什么？
L4. 已完成哪些步骤？下一步、障碍、需要的资源或帮助是什么？
L5. 哪些人、项目、机构或地点与未来计划相关？
L6. 哪些旧目标已完成、放弃或变化？原因与时间是什么？
L7. 第一遍问题中还有哪些重要主题遗漏、描述不准或希望撤回/补充？
L8. 现在是否愿意生成第一版 HTML Atlas，查看关系、时间线和缺口？之后想先深入哪个主题？
