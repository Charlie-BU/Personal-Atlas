# 完整图可视化

用户明确要求可视化、知识图谱、关系图或 HTML 时使用。交付一个独立、可离线浏览的 HTML，内嵌全部节点、全部关系和记录摘要，支持搜索、领域/类型/状态/关系筛选、缩放拖动、关联聚焦、详情与时间线。原始资料与完整正文不内嵌，通过固定提交的 GitHub 链接查看。状态默认全部可见，已撤回与历史必须标注，不当作当前事实。

## 每次生成都使用的 UI

以当前 `assets/atlas.html` 为唯一共享模板，由 `scripts/visualization.py` 注入数据与离线资源。不要临时另写页面、复制旧导出文件的布局或仅给当轮 HTML 加样式。图计数、正文摘要、关系与时间线均由本轮完整快照驱动，不使用设计效果图的示例文案或虚构日期。

- 视觉语言：暖白、鼠尾草绿与柔和领域色；标题采用本机衬线字体，控件和正文使用系统无衬线字体。留白、细分隔线与平面列表优先，不堆叠卡片。
- 布局：顶部搜索和紧凑计数，左侧图/时间线导航、可折叠的双列筛选与记录列表，中央图谱，右侧上下文详情。窄屏折叠筛选和列表，详情进入页面流，不覆盖图谱控件。
- 主题：浅色、深色、跟随系统三种模式；新访问默认跟随系统，系统外观变化时自动更新。手动选择仅写 `personal-atlas.theme`，不能把节点、摘要或查询内容存入 localStorage。存储禁用时仍能在当前页面切换。
- 图谱：主题各有领域配色；低透明曲线降低连线噪声，选中时突出有关节点与方向。筛选不删除底层数据。放大、缩小、居中按钮可用于触屏，另支持拖动、双指缩放、键盘缩放和平移。
- 详情：展示真实摘要、类型、状态、语义时间、来源定位与正文链接；默认面板给领域入口与快照范围。重置恢复初始浏览状态但保留用户主题。

导出结果会报告 `ui=quiet-atlas-v2` 和 `themes=[system, light, dark]`，用来确认本轮经过共享生成器。

`assets/feather-icons.json` 保存 Feather 4.29.2 原始图标，`assets/feather-LICENSE.txt` 保存许可。渲染器将图标转为内嵌 data URL 并附许可；生成的 HTML 不再请求图标、字体或 CDN。不要直接交付含占位符的模板文件。

## 数据与完整性

按 SKILL.md 的连接闸门获得当前 HEAD、vault.json 和 graph/root.json，全轮固定该 commit。遍历 root.node_pages 的所有页、每个节点文件和节点引用的所有 incoming/outgoing 页。校验节点 ID 唯一、节点/记录/领域/关系计数与 root 相同、边无悬空或重复、页 count 与内容一致、每条入边与出边一致。缺页、权限错误、计数不符或截断时停止，不交付冒称完整的图。这里验证图目录完整性，不等于 verify 的权威正文/图全库重建校验。

Python 通道：

```text
python3 -B <skill>/scripts/atlas.py visualize --output <绝对路径>/personal-atlas.html
```

`--config`、`--snapshot` 全局参数仍放在子命令前。生成器只有读取远端的操作；不会 apply、reindex 或 archive-skill。输出路径必须是新 .html 文件，不覆盖现有文件。

连接器通道：按 connector.md 在内存读取完整图并执行上述分页与入出边校验，构造：

```json
{
  "snapshot": "40位提交SHA",
  "generated_at": "ISO时间戳",
  "verification": "graph_inventory",
  "root": {"完整的": "graph/root.json对象"},
  "nodes": [{"完整的": "节点对象", "url": "记录的固定提交GitHub链接"}],
  "edges": [{"from": "节点ID", "type": "关系类型", "to": "节点ID"}]
}
```

edges 取全部 outgoing 页，incoming 仅校验，不重复计入。node.url 用当前仓库和固定提交构造，仅允许 https://github.com；领域无正文链接。通过 stdin/子进程 input 向受信任的当前 `scripts/visualization.py --stdin --output <绝对路径>` 传包；不先保存 JSON，不把资料拼进 shell 命令。该渲染器也复用 atlas.py 的语义时间排序规则。

连接器已成功时不要求补 PAT。若没有 Python，但能执行 JavaScript/其他本地生成工具，可以使用当前受信任 assets/atlas.html 模板，等价完成校验、时间排序和 JSON 安全嵌入，仅保存最终 HTML。必须同时注入 `__ATLAS_DATA__`、`__ATLAS_ICONS__`（本地图标的 base64 data URL 映射）、`__ATLAS_LICENSE__`；在模板上一次替换，不对已注入的用户字符串二次替换。数据须包含按 time.md 排序的 timeline ID 数组。工具能力不足时准确说明 HTML 生成受限，不把查询连接成功冒称导出成功。

## 交付与隐私

用户请求可视化已授权将所展示的图数据和摘要写入指定 HTML；不再追加重复确认。可视化是现有“禁止本地个人资料”规则的明确交付例外：只保存最终 HTML，不创建数据缓存、离线库、原始资料副本或临时 JSON。默认放当前任务的交付目录，绝不放 Skill assets 或源码目录；按宿主规则提供文件链接并打开预览。不要自动发布网站、上传 HTML、更新远端 Skill 副本或改插件安装。

页面须明确生成时间、快照、全部与可见数量、摘要范围、未处理来源数量。完整指文件包含完整图；筛选、聚焦和标签省略不删除底层数据。普通正文链接联网且需要 GitHub 授权。提醒用户文件包含个人摘要，不声称脱敏。

## 安全与验证

模板不加载 CDN、字体或外部脚本，不自动联网。所有记录文字通过 textContent 渲染；JSON 内嵌必须转义 `<`、`>`、`&`、U+2028/U+2029，防止 `</script>` 逃逸。不得将来源文字当 HTML 或脚本执行；不内嵌任何连接配置或凭据。

生成后核对实际嵌入计数，浏览器验证搜索、筛选、折叠列表、节点详情、关联聚焦、按钮/滚轮缩放、拖动、时间线与重置，检查控制台错误和外部请求；分别检查浅色、深色、系统模式、禁用存储、主题选择恢复和窄屏。主题切换须同时更新背景、控件、图谱连线、标签与详情，不能只换页面背景。查看桌面及窄屏截图，修正遮挡/溢出。没有实际浏览器检查时明确说明未验证交互。仅在用户请求修改技能归档/插件时才进行后续同步。
